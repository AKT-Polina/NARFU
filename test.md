В экосистеме C++ библиотеки делятся на две основные категории: встроенная Стандартная библиотека (C++ Standard Library / STL), которая доступна сразу «из коробки», и сторонние (third-party) библиотеки, которые разработчики подключают под конкретные задачи (графика, сети, математика, игры). [1] (https://ru.wikipedia.org/wiki/%D0%A1%D1%82%D0%B0%D0%BD%D0%B4%D0%B0%D1%80%D1%82%D0%BD%D0%B0%D1%8F_%D0%B1%D0%B8%D0%B1%D0%BB%D0%B8%D0%BE%D1%82%D0%B5%D0%BA%D0%B0_%D1%8F%D0%B7%D1%8B%D0%BA%D0%B0_C%2B%2B), [2] (https://foxminded.ua/ru/top-c-plus-plus-biblioteki/)
Ниже собраны самые важные и популярные библиотеки, структурированные по их назначению.

1. Встроенная стандартная библиотека (C++ Standard Library)

Это фундамент языка. Она стандартизирована комитетом ISO и оптимизирована для работы на любой платформе. Её ключевая часть — STL (Standard Template Library). [1] (https://learn.microsoft.com/ru-ru/cpp/cpp/c-cpp-language-and-standard-libraries?view=msvc-170), [2] (https://ru.linkedin.com/pulse/essential-libraries-enhancing-c-every-developer-should-ayman-alheraki-gbptf?tl=ru), [3] (http://aco.ifmo.ru/el_books/applied_programming/lectures/part2-1.html), [4] (https://ru.wikipedia.org/wiki/%D0%A1%D1%82%D0%B0%D0%BD%D0%B4%D0%B0%D1%80%D1%82%D0%BD%D0%B0%D1%8F_%D0%B1%D0%B8%D0%B1%D0%BB%D0%B8%D0%BE%D1%82%D0%B5%D0%BA%D0%B0_%D1%8F%D0%B7%D1%8B%D0%BA%D0%B0_C%2B%2B), [5] (https://foxminded.ua/ru/top-c-plus-plus-biblioteki/)
• Контейнеры (<vector>, <list>, <map>, <set>): структуры данных для хранения и управления коллекциями объектов.
• Алгоритмы (<algorithm>): готовые функции для сортировки, поиска, фильтрации и трансформации данных.
• Ввод-вывод (<iostream>, <fstream>): работа с консолью и чтение/запись файлов.
• Потоки (<thread>, <mutex>): инструменты для создания многопоточных и параллельных приложений.
• Строки (<string>): полноценная поддержка работы с текстовыми данными. [1] (https://prostocpp.narod.ru/biblioteki.html), [2] (http://aco.ifmo.ru/el_books/applied_programming/lectures/part2-1.html), [3] (https://foxminded.ua/ru/top-c-plus-plus-biblioteki/), [4] (https://ru.cppreference.com/cpp/standard_library)

2. Главная сторонняя библиотека общего назначения

• Boost — самая важная сторонняя библиотека в мире C++. Она содержит сотни модулей (работа со строками, сетью, регулярными выражениями, умными указателями, асинхронностью). Многие возможности Boost со временем тестируются сообществом и переносятся напрямую в официальный стандарт языка (как это произошло, например, с std::filesystem). 3. Специализированные библиотеки по направлениям


Направление	Название библиотеки	Для чего используется
Граф. интерфейсы (GUI)	Qt	Мировой стандарт для кроссплатформенных приложений с интерфейсом (от десктопа до автопрома).
	wxWidgets, SFML, Juce	Альтернативные легковесные фреймворки для GUI и медиа.
Разработка игр	SDL 2.0 / SFML	Низкоуровневая работа с графикой, звуком, вводом (мышь/клавиатура).
	Unreal Engine	Мощнейший игровой движок (код пишется на C++).
Компьютерное зрение	OpenCV	Обработка изображений, видеопотоков, распознавание лиц и объектов.
Нейросети и AI	TensorFlow / PyTorch	Обучение и высокопроизводительный запуск математических моделей ИИ.
Математика	Eigen	Высокопроизводительная линейная алгебра (матрицы, векторы).
Сеть и интернет	libcurl	Стандарт для выполнения HTTP-запросов и работы с сетевыми протоколами.
	Asio	Библиотека (часть Boost) для создания быстрых сетевых серверов.
Тестирование	GoogleTest (gTest)	Главный стандарт индустрии для написания модульных тестов (Unit-tests).
